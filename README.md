# Algoritmo do Apocalipse (Versão 1.0)

## Descrição do Projeto
Este é um algoritmo em JavaScript capaz de descobrir o dia da semana de qualquer data do Calendário Gregoriano, usando a lógica matemática da Congruência de Zeller.

## Sobre o Projeto
Criei este código como estudante de Ciência da Computação para praticar lógica de programação e entender como transformar fórmulas matemáticas interessantes em código. Esta é a **Versão 1 (V1)** do projeto, focada em fazer a lógica funcionar da maneira mais direta possível.

## Tecnologias Utilizadas
- JavaScript

## Como Executar
O código utiliza comandos simples de entrada e saída (`prompt` e `console.log`). Para testar:
1. Abra qualquer navegador (ou compilador de JavaScript) e acesse as Ferramentas do Desenvolvedor (tecla `F12`).
2. Vá até a aba **Console**.
3. Cole o código e execute.
